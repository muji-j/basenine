# BaseNine

日本プロ野球(NPB)の記録を、ふつうの人が見やすい形にまとめて表示する**静的サイト**です。

> ⚠**このリポジトリはコードだけです。** 収集した原本データ・DB は含まれません。
> 公開サイトは Cloudflare Access の内側にあり、いまは知人限定です。

---

## これは何をするものか

- 選手・球団の成績、リーグ順位、セイバーメトリクス、スプリット、投手×打者の対戦成績
- **サーバーがありません** — 全ページを事前に生成して配信します
- 数値は公表記録をもとに**当サイトが独自に再計算**したものです。**原本の表を再現しません**

## ⚠出典と権利について

- 出典は**日本野球機構(NPB)公式サイト** [npb.jp](https://npb.jp/) です。全画面に出典を明記しています。
- 一部のドラフト情報は **ja.wikipedia**(CC BY-SA 4.0)由来です。該当する画面にその旨を表示します。
- **選手の写真・球団ロゴは使用していません。** 記録は事実ですが、写真とロゴは別の権利です。
- 収集は **1リクエスト/2〜5秒・同時1接続・連絡先を書いた User-Agent** で行い、1日3回のバッチだけです。

⚠**このリポジトリのコードをそのまま動かすと、あなたの連絡先で npb.jp にアクセスが行きます。**
`BB_ARCHIVER_CONTACT` を必ず自分の**届く**アドレスにしてください。

## 動かす

```
npm ci
npm test
```

⚠**テスト用の npb.jp 原本 fixture はこのリポジトリにありません**(権利上の理由)。
取得方法は `packages/parser/test/fixtures/README.md` にあります。

## 構成

| パッケージ | 役割 |
|---|---|
| `domain` | 球団・シーズンなどの語彙 |
| `parser` | 取得したページを読む |
| `store` | SQLite への格納 |
| `aggregate` · `metrics` | 集計と指標 |
| `archiver` | 収集(礼儀を守る HTTP) |
| `web` | 静的ページ生成 |

## ドキュメント

- `CLAUDE.md` — このプロジェクトの決まりごと
- `docs/decisions/` — 意思決定の記録
- `docs/sources/` — データ源の調査と判定
- `docs/operations/` — 運用手順

⚠**ドキュメントは韓国語**です。開発者の作業言語がそうだったためで、
製品の表示言語(日本語)とは別です。
