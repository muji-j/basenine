## D8 기타 — 이 도메인 고유의 함정

- ⚠**받고 있는데 안 읽던 것**(`CLAUDE.md` §2-2-1) — **네 번 나왔다.** 「새 데이터가 필요하다」고 판단하기 전에
  **이미 받아 둔 페이지를 먼저 열어 봤는가**를 감사 항목으로 둔다. 네 번째는 「안 여는 파일」이 아니라
  **「열고 있는데 안 보는 칸」**이었다 — 받는 페이지 목록만 확인해서는 안 잡힌다.
- ⚠**이름을 바꿔야 하는 세이버는 패스**(§2-2-2) — 닫힌 목록(WAR·xFIP·세이버의 통산 전환)을 **다시 열지 않았는가.**
- ⚠**자체 계산 지표는 표준과 다른 이름**(SRC) — 같은 이름에 다른 값이면 거짓말이 된다.

# D1~D7 스택 구체값

## D1 · security — **활성(경량)**

공개 데이터 기반이라 기밀 축은 가볍고, **남용·비용 폭주와 공급망**이 주 위험이다(`CLAUDE.md` §0 제약9).

- 인가는 **코드에 없다** — Cloudflare Access(엣지)가 한다. `scripts/access-config.ts` 가 허용목록의 정본이고
  **매일 배포가 대조**한다. ⚠**「토큰이 유효한가」와 「지금도 명단에 있는가」는 다른 질문이다**(§2-5).
- 외부 입력은 **스크레이핑 결과와 URL 파라미터**뿐이다. 폼 제출·로그인 폼이 **0건**이다.
- **CI 무료 분**이 유한하다 — 비용 폭주는 요금이 아니라 **분 소진으로 배포가 죽는** 형태로 온다.

## D2 · concurrency — **활성**

- **멱등**(M5)이 최우선. 수집·적재·배포가 전부 재시도·크론 중복 기동을 전제한다.
- ⚠**SQLite 트랜잭션이 `BEGIN` 이다**(`packages/store/src/db.ts` · `IMMEDIATE` 가 아니다).
  단일 작성자 전제가 깨지는 경로가 생기면 여기부터 본다.
- **수집 창**: `MAX_CATCHUP_DAYS` 로 빠진 날을 메운다. ⚠정상·휴식일에 요청이 1건도 안 느는지를 시험이 고정한다.

### D2-c · 클라이언트측
정적 페이지라 서버 왕복이 없다. 클라이언트 JS 는 **색인 `fetch` 하나**뿐이고 폴링·스트리밍이 **0건**이다.

## D3 · correctness — **활성**

- **파서 실패는 실패로**(M7). 빈 값·0 으로 흘리면 「기록 급락」이라는 거짓말이 된다.
- **선수는 ID 로**(M10). 이름 문자열 조인 금지.
- **미수집·0·결측을 구별**(M11).
- 고정 픽스처는 **`packages/parser/test/fixtures/`**(추적 7파일). ⚠`docs/sources/samples/` 가 **아니다**(무추적).

## D4 · perf — **활성**

- 걸리는 것은 전송량이 아니라 **DOM 크기**다. 선수 페이지가 배포물의 대부분이다.
- **Pages 파일 수 상한**과 **CI 분**이 실제 제약이다. ⚠수치의 정본은 `CLAUDE.md` §2-2 와 `docs/operations/deploy.md`.
- ⚠**로컬 시간으로 CI 병목을 판단하지 마라** — 실측에서 순위가 뒤집혔다(§6).

## D5 · a11y — **활성**

`npm run preview` 로 띄운다. ⚠**`file://` 금지**(색인 `fetch` 가 막혀 검색이 죽은 화면을 재게 된다).
테마는 `data-theme` 속성으로 전환하고 **light/dark 를 각각 잰다**. 표에 이름이 없는 것이 실제 결함으로 나온 이력이 있다.

## D6 · design — **활성**

- 「AI틱함」 목록의 정본은 **워크스페이스 루트 `CLAUDE.md` §7**, 이 제품의 추가분은
  `.claude/agents/design-graphics-engineer.md`.
- ⚠**라벨 강조 원칙에 도메인 예외가 있다**(§6) — 이 제품은 **숫자가 곧 내용**이라 값을 주역으로 둔다.
  **원칙 위반으로 지적하지 마라.** 대신 **분모가 값에 인접하는가**를 본다.
- 선수 사진·구단 로고·엠블럼은 **쓰지 않는다**(§6).

## D7 · consistency — **활성**

정본↔사본 구조는 **없다**(단일 사이트). 대신 이 저장소에는 **문서↔코드·DB 정합**이라는 강한 축이 있다:

- `scripts/test/doc-figures.test.ts` 가 `CLAUDE.md` · `docs/metrics/` · `docs/operations/deploy.md` 의
  수치를 **DB 와 소스로 다시 센다.** ⚠**그 시험이 지키는 문장을 오버레이·보고서에 복사하지 마라.**
- ⚠**고침이 문서를 낡게 하는** 모양이 반복됐다 — 코드를 고쳤으면 그것을 서술한 문장을 함께 고쳤는가.

## 이 스택 고유의 「스크린으로는 못 잡는 것」

- **단위 이름이 갈리는 것** — 값이 전부 맞아서 타입도 시험도 못 잡는다(위 ② 참조).
- **에러가 아니라 빈 화면** — 역할 판정이 틀려 투수 스플릿이 통째로 사라진 적이 있다(§2-2-1).
- **배포는 됐는데 사용자가 옛 화면을 보는 것** — 증거가 전부 초록이었다(§6).
