## 2. 정답지 대조 — **불일치 0건**

npb.jp `draftlist_{team}.html` 표 아래 문장을 구조화해 wikipedia 그리드와 맞췄다.

**주석 문법**(실측 · 40건 전건이 이 하나로 파싱됨):
```
※{1巡目|1位}[（第N回）]： [{선수명}{投手|内野手|外野手|捕手}で]{구단}[、{구단}…]と重複、抽選で{外れる|確定}
```
- **낙첨(`外れる`)이면 선수명을 쓴다**(그 팀 표에는 다른 선수가 실려 있으므로).
- **당첨(`確定`)이면 선수명을 생략한다**(그 팀 표의 그 회차 값이 곧 그 선수).
- `（第N回）` 는 **그 구단의 주석이 2건 이상일 때만** 붙는다. 없으면 주석 순서 = 회차(2013 中日 실측).
- 전각 숫자(`※１巡目`)가 섞인다(2006·2007) → **NFKC 정규화 먼저.**
- ⚠**두 주석이 `<br>` 없이 붙어 있는 경우가 있다**(2007 西武) — `<p>` 단위가 아니라 **`※` 로 잘라라.**

### 경합 표시 — **닫힌 어휘다**

`<td>` 의 `style` 에 **오직 두 프로퍼티만** 나온다(4,760칸 전수 · 그 밖 CSS **0건**):

| 프로퍼티 | 값역 |
|---|---|
| `background-color` | 추첨 팔레트 **6색** `#fcc #ccf #cfc #ffc #cff #fcf` · 비추첨 **1색** `#ccc` |
| `font-weight` | **`normal` 뿐**(다른 값 0건) |

**굵음의 출처는 표 자신이다** — 21/21 그리드가 `<table style="…font-weight:bold…">` 를 갖는다.
따라서 **셀에 `font-weight` 가 없으면 굵고, `normal` 이면 안 굵다.**

⚠**문자열로 매칭하지 마라.** 같은 표 안에서 `…normal;` 와 `…normal` 가 공존한다(2019).
**CSS를 프로퍼티 단위로 파싱하라.**

### 당첨·낙첨

```
같은 행 · 같은 background-color   = 하나의 경합 그룹
그 그룹에서 font-weight 미지정    = 당첨(교섭권 획득)
그 그룹에서 font-weight:normal    = 낙첨
```

⚠**「같은 행」이 필수다.** 색은 **다른 행에서 재사용된다** — 2013 `#fcc`(1巡目① 松井裕樹 / 1巡目③ 岩貞祐太) ·
2017 `#fcc`(清宮 / 馬場) · 2023 `#ccf`(武内 / 細野). **표 전체를 색으로 묶으면 다른 선수가 한 그룹이 된다.**

### ⚠`#ccc`(회색) — 뜻은 확인됐고 **범위는 불완전하다**. 그래서 안 쓴다 (2026-09-06 실측)

`S8` 은 회색을 「별도 축(입단 거부/계약 불성립)」으로 넘기라고만 적었다. **그걸 실제로 쓰려다
게이트에서 걸렸다.** 다음 사람이 같은 자리에서 멈추지 않도록 여기 적는다.

**뜻은 우리 추론이 아니다 — 기사가 스스로 적는다:**

> 背景色が暗い選手は入団拒否した選手。 — 2006 · 2009 기사 본문

**게이트**: 회색 칸 수 ↔ 같은 기사 요약 상자의 `入団拒否 N名`. **두 자리가 서로 독립이다.**

| | 값 |
|---|---|
| 아카이브 | **22개 연도** · 셀 22,455개 중 회색 **10개** |
| 일치 | **4년**(2014 · 2015 · 2016 · 2024) — 각 1 = 1 |
| ⚠**불일치** | **1년 — 2011: 기사는 `入団拒否 1名`, 회색 칸 0개** |

```
회색  ⇒  입단 거부      (뒷받침됨)
```

**세는 순간** 거짓이 된다. 쓰려면 **완전한 목록을 주는 출처**를 먼저 찾아야 한다.
⚠**npb 로는 못 메운다**: 우리 아카이브의 npb 원본에 `入団拒否`·`未入団`·`入団せず` 가
**0건**이다(회색에 걸린 8개 연도 전수). 이름 10개는 전부 들어 있으니 **대조가 가능한데
말하는 어휘가 없는 것**이다.

## 4. 파서 규칙 (그대로 옮길 수 있게)

```
S0  URL      https://ja.wikipedia.org/wiki/{YYYY}年度新人選手選択会議_(日本プロ野球)
             — /wiki/ 만. /w/ · /api/ 는 robots Disallow.
             — ⚠Last-Modified 가 온다(19/19) → L7 조건부 요청 성립.
                npb.jp 와 다르다(그쪽은 0/9).

S1  섹션     h2 의 id 가 다음 중 하나:
               指名選手一覧 | 選択希望選手一覧 | 指名選手一覧（指名順表記）
             ⚠하나도 없으면 실패(빈 값 금지 · M7).

S2  표       그 h2 부터 다음 h2 까지에서 class 에 "wikitable" 이 있는 첫 <table>.
             ⚠없으면 「미개최/미기재」로 확정하고 종료(2026이 이 상태).
             ⚠class="box-節スタブ" 안내가 있다고 데이터가 없는 게 아니다(2019 는 둘 다 있다).
                판정은 **wikitable 유무**로 한다.
             ⚠표 스타일에 font-weight:bold 가 없으면 실패 — 굵기 규칙의 전제다.

S3  격자     rowspan/colspan 을 펼쳐 2차원 격자로. ⚠생략하면 2007 이 조용히 어긋난다.

S4  머리행   첫 칸이 「チーム」 또는 「指名順」 인 행. 정확히 1개(21/21).
             그 행의 2~13번째가 구단 약칭. 폭은 반드시 13.

S5  배너     colspan=13 인 행. 텍스트는 4종만:
               支配下選手 | 育成選手 | 高校生 | 大学生・社会人
             ⚠그 밖이면 실패. 이후 행의 소속 구획이 여기서 정해진다.

S6  행 라벨  ^1(巡目|位)([1-9]|[①-④])       → 1순위 입찰, 회차
             ^(\d+)(巡目|位)(→|←)            → N순위, 방향
             ^1(巡目|位)([1-9]|[①-④])(→|←)  → 1순위 회차 + 방향(2005·2006)
             ^希望枠                          → 희망입단枠(추첨 아님)
             ⚠넷 중 어디에도 안 맞으면 실패.

S7  셀 값    "---" → 미지명(⚠미수집이 아니다 · M11)
             그 밖 → 선수. 이름은 두 벌로 저장:
               display   = 셀 텍스트(<br> 는 빈 문자열로 이어붙임 · <sup class="mw-ref"> 제거)
               canonical = <a title="..."> 에서 " (存在しないページ)" 제거
             ⚠둘이 다른 케이스 8건. **어느 쪽도 항상 옳지 않다.**
               2024 ラマルギービンラタナヤケ(표시) ↔ ラタナヤケ・ラマル・ギービン(title) — 어순까지 다르다.
               **이름 문자열로 조인하지 마라**(M10).

S8  경합     (행, background-color) 로 묶는다. 팔레트는 6색으로 한정.
             #ccc 는 추첨이 아니다 → 별도 축(입단 거부/계약 불성립)으로.
             그룹 안: font-weight 미지정 = 당첨 / normal = 낙첨.

S9  기록     source · fetched_at · revision(본문 해시 + Last-Modified) ·
             license = CC BY-SA 4.0 · 기사 URL 을 레코드에 남긴다(M4 · L3).
```

## 11. 사용자 요구(「불일치가 안 일어나게」)에 대한 정직한 답

- **일어난 불일치는 2건이고 둘 다 「누가 뽑혔나」가 아니라 「이름을 어떻게 쓰나」였다.**
- **경합·추첨 축에서는 대조 40건 전부 일치, 반대 방향 0건.**
- 그러나 ⚠**「불일치가 안 일어난다」를 보장할 수는 없다.** 보장할 수 있는 것은
  **「불일치가 나면 조용하지 않다」**뿐이다 — INV-1~7 + X-3 을 시험으로 걸면 규칙이 흔들린 해에
  **빈 화면이 아니라 붉은 실패**가 난다.
- ⚠**그래서 이 소스는 「채용」이 아니라 「조건부 채용」이다.** 조건 **다섯**:
  1. 연도마다 규칙을 사람이 확인
  2. **INV-1~7 을 시험으로 강제 · 위반 시 실패**
  3. 표를 재현하지 않는다(L2 · CC BY-SA 계승)
  4. 출처·라이선스·`Last-Modified` 를 레코드에 남긴다(M4 · L3)
  5. **매년 `schedule.html` 의 웨이버 순서로 열 머리를 대조한다**(INV-7 — 주석이 끊긴 뒤 **남은 유일한 독립 검사**)
