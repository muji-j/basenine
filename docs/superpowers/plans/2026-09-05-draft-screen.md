# 드래프트 화면 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** DB 에 들어간 드래프트(**21시즌 · 지명 2,234행 · 입찰 374행**)를 **시즌별 페이지**로 보인다 — 사용자가 처음 요청한 그것이다.

**Architecture:** 이 저장소의 페이지 관용을 그대로 따른다 — `query.ts`(**유일한 DB 접점**) → `renderDraftPage(data, ctx): RawHtml` → `site.ts` 의 `seasonPaths()`·`buildSite()` 에 등록. **DB 를 렌더러가 모른다.**

**Tech Stack:** Node ≥24 · TypeScript · `node:test` · 태그드 템플릿 `html`

앞선 두 계획(`2026-09-04-draft-npb-source.md` · `2026-09-05-draft-collector.md`)에서
**내가 쓴 코드가 반복해서 실물과 어긋났다**: 정규식 3연속 0건 · 「아무것도 안 재는 SQL」 ·
호스트 · `BlobMeta.revision` 이 숫자 · CLI 인자 형태 · `as never` 로 타입을 뚫은 시험.

**매번 실물이 옳았다.** 그래서 이 계획은 **구조와 계약을 정확히 쓰고, 코드는 조사로 확인된 것만** 쓴다.
⚠**「먼저 실측하라」로 남긴 것은 게으름이 아니라 이 브랜치에서 배운 것이다.**

## Global Constraints

- **M1** — 지표 계산·어휘를 두 벌 두지 마라. ⚠**`query.ts` 가 유일한 DB 접점이고 렌더러는 DB 를 모른다.** 지표 라벨·분모 단위는 `glossary.ts` 가 정본이다.
- **M2** — **분모 없는 비율을 렌더링하지 마라.**
- **M11** — 미수집·0·결측을 구별한다.
- **M12** — 빈 상태를 **로딩 / 데이터없음 / 수집실패 / 시즌외**로 구분한다(`layout.ts` 의 `DataState`).
- **L2** — ⚠**원본 표 레이아웃을 재현하지 마라.** wikipedia 그리드(행=회차 × 열=12구단)를 그대로 옮기지 않고 **경합 그룹 단위로 재구성**한다.
- **L3** — **출처를 화면에 명기**한다.
- **L5·L6** — ⚠**선수 사진·구단 로고·엠블럼을 쓰지 마라.**
- **UI**(루트 §7) — **라벨 강조 원칙의 도메인 예외**: 값을 주역으로 두되 **라벨과 분모를 반드시 인접**시킨다. ⚠**「AI틱함」 회피**: 보라·파랑 그라데이션 · 균질 카드 그리드 · 이모지 아이콘 · 목적 없는 glassmorphism · 중앙정렬 히어로 금지.
- **분모를 항상 표기**하고 **「0건」과 「안 쟀음」을 구별**한다.

### ⚠조건부 ① — 상태 띠의 선 대비가 **조건부로만** 통과한다

새 `.empty[data-state]` 띠의 선은 **1.40(light) / 1.42(dark)** 로 비텍스트 3:1 미달이다.
감사가 **결함으로 세지 않은 근거 셋**: ⑴**상태를 식별하는 유일한 수단이 아니다** —
문장 첫 낱말(`公表されていません` / `まだ収集していません` / `シーズン外` / `取得できていません`)이
**본문 대비로** 같은 것을 말한다 ⑵띠는 **면적이 크다**(전폭 × 29px)라 1.1:1 계단이 실제로 보인다
(크롭 8장 확인) ⑶강제 색 모드에서 `border-left-style` 은 **살아남는다**.

⚠**그래서 다음 사람에게 남기는 조건은 이것이다:**
> **문장을 짧게 줄여 첫 낱말을 없애면 그 순간 이 띠는 WCAG 1.4.11 대상이 되고 1.40:1 로 떨어진다.**

### ⚠조건부 ② — 띠를 주는 기준의 **이름이 실제와 다르다**(P3 · 오늘 재현 불가)

CSS 주석은 실선을 **「출처가 껐다 · 정말로 0건이었다」**로 정의하는데, 코드가 실제로 가르는 것은
**「`stateNote()` 를 통과했는가」**다. `{kind:"empty"}`(= `「${season}年に交渉権の訂正・入団拒否は
ありませんでした」` — **확정 답변**)도 실선 띠를 받는데, 손으로 적은 같은 성격의 답
(`この回の競合はありません。` · `この区分の入札は記録が0件です。`)은 아무것도 안 받는다.

⚠**오늘은 재현되지 않는다** — dist 9장의 `data-state` 는 `offseason`·`uncollected`·`unpublished`
셋뿐이고 **`empty` 는 0건**이다. **`DRAFT_NOTES_COLLECTED` 가 `true` 가 되는 날** 한 화면에 두 모양이 선다.

→ **그때 둘 중 하나만 하면 된다**: 주석의 정의를 실제와 맞추거나(「`stateNote` 가 내는 것에만 띠」),
`empty` 를 띠에서 빼거나. ⚠**지금 코드를 건드릴 이유는 없다**(감사 판정).

### ⚠다음 감사 대상 — `matchup.html`

같은 결함(마커가 라벨에서 멀다)이 **실재한다**: `.pickfold>summary` 폭 548px 에
`margin-left` 해석값 **479.53px**(감사 실측). ⚠**단 성질이 완전히 같지는 않다** —
거기 summary 는 **10px** 이라 **크기 역전은 없고 마커 거리 한 축만 겹친다.**
드래프트 수정자가 **자기 주석에 「対戦은 250px 단이라 괜찮다」고 적었다가 재 보니 거짓이라 고쳤고**,
**안 옮긴 진짜 이유는 「그 화면이 감사 대상이 아니었다」는 것뿐**이라고 남겼다.

### 남은 짐 — 감사가 「이 변경이 만든 게 아니다」로 판정한 것

- **index·ranking 의 `順位表（横スクロール）`×2 중복** — 옛 코드로도 `順位（横スクロール）`×2 였음을
  같은 DOM 에서 재현 확인. ⚠**뿌리는 `<table aria-label="順位表">` 가 두 리그에 같은 이름을 쓰는 것**이다 —
  **그 화면을 감사할 때 표 이름부터 고쳐야 한다.** 스크롤 영역은 그 사본일 뿐이다.
- **탭 들여놓기가 JS 에 의존** — 감사 판정: **받아들인다.** JS 가 죽어도 **잃는 것이 0**이고
  (상자는 손으로 굴러가고 **27/27 에서 경계에 부분 탭이 걸쳐 힌트가 남는다**) 고치기 전 상태로 떨어질 뿐이다.

## ⚠측정 도구가 이 브랜치에서 **여섯 번** 거짓을 냈다 — 매번 다른 원인

「돌렸다」와 「돌아갔다」가 다르다는 것이 이 브랜치의 반복 주제였다. **숫자를 받기 전에
그 도구가 실제로 무엇을 했는지 확인하라.**

| # | 무엇이 거짓을 냈나 | 어떻게 드러났나 |
|---|---|---|
| 1 | 뮤테이션 보고가 **「(로드 실패)」만** 찍었다 | 무엇이 무엇을 죽였는지 모른 채 숫자만 읽을 뻔했다 |
| 2 | **ANSI 를 `/\[\d+m/g` 로만** 지워 ESC 가 남았다 | `NO_RUN` 17건 = **「전부 구문오류」로 보고할 뻔** — 실제로는 전부 정상 실행 |
| 3 | **CRLF/LF 혼재**(`core.autocrlf=true` · `.gitattributes` 없음) | 여러 줄 앵커가 안 맞아 `NOT_APPLIED` — **「그 코드가 없다」로 읽을 뻔** |
| 4 | **`UnicodeEncodeError: cp932`** | 파이썬 출력이 죽어 **「결과 0건」으로 보일 뻔**(→ `PYTHONIOENCODING=utf-8`) |
| 5 | **`node --test` 가 `#` 이 아니라 `ℹ`+ANSI** 로 찍는다 | `grep "^# tests"` 가 **0건** — 도구가 아니라 **패턴이 틀렸다** |
| 6 | ⚠**셸이 페이로드를 조용히 망가뜨린다** | `python - <<'PY'` · `node -e` 에 **NUL·백슬래시**가 들면 값이 바뀐다(`before 1 after 1`). **파일로 써서 실행**해야 맞는다 |

⚠**그리고 파이프가 종료코드를 덮어쓴다** — 이 브랜치에서 **구현자와 내가 각각 한 번씩** `| tail` 로
재서 `tail` 의 종료코드를 읽고 **「통과」라고 잘못 보고했다.** `CLAUDE.md` 가 경고하는 그것이다.

### ⚠날문자 NUL 이 세 번 들어갔다 — 세 번째는 **이 문서 자신**이다

Task 6 과 화면 조회층에서 각각. **`grep` 이 그 파일을 「Binary file … matches」로 처리해
내용을 한 줄도 안 보여 주고**, Edit 도 그 구간을 못 맞춘다.
→ **맵 키 구분자 같은 곳에 날문자를 쓰지 말고 `\u0000` 이스케이프로 써라.** 값은 같고 소스는 텍스트다.

⚠⚠**그리고 바로 위 문단을 쓰면서 세 번째가 들어갔다.**
「날문자를 쓰지 말라」는 줄을 쓰는 편집이 **날문자를 넣었고**, 그 즉시 이 문서가
`grep` 에서 바이너리가 됐다. 고친 방법은 **파일로 쓴 스크립트**다(위 표 6번과 같다).
⚠**임의의 도구가 아니라 편집 행위 자체가 경로다** — 소스만 의심하면 문서에서 다시 난다.
**바꿔 썼으면 `grep -c '' <파일>` 로 텍스트인지 한 번 확인하라** — 바이너리면 행 수가 안 나온다.
