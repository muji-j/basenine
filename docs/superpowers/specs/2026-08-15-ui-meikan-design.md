## 1. 결정

**C안 名鑑을 기준으로 삼는다**(2026-08-15 사용자 확정).

그리고 **A안·B안을 경쟁안에서 블록으로 강등한다.** 셋 중 하나를 고르는 문제가 아니라,
名鑑이라는 그릇 안에 무엇을 담을지의 문제로 다시 놓는다.

| 원래 | 이후 |
|---|---|
| A 記録票 (경쟁안) | **打席記録 블록** — 켜면 명감 안에 들어온다 |
| B 状況盤 (경쟁안) | **得点期待値 블록** — 동상 |
| C 名鑑 (경쟁안) | **페이지의 정체성** — 배색·타이포·괘선·밀도 |

## 2. 名鑑이 정체성으로 가져오는 것

| 요소 | 내용 | 왜 |
|---|---|---|
| **배면(背表紙)** | 왼쪽 세로 띠가 **선수의 소속 구단 색**을 입는다 | 페이지가 누구의 것인지를 색 하나로 말한다. 12구단이 각자 다른 페이지가 된다 |
| 타이포 | 작고 촘촘한 본문 + 등번호·이름만 크게 | 야구 팬은 숫자를 많이·빠르게 본다. 여백만 넓은 화면은 이 제품에서 실패다 |
| 괘선 | 머리카락 굵기의 밑줄로 항목을 가른다 | 카드·그림자를 쓰지 않는다. 인쇄물의 질감 |
| 숫자 | `tabular-nums` 고정폭, 우측 정렬 | 세로로 훑을 수 있어야 한다 |
| 순위 배지 | 구단 색 바탕의 작은 사각 | 「1位」가 색을 얻어 눈에 걸린다 |

⚠**구단 색이 12벌 필요하다.** 阪神의 노랑처럼 강한 색은 글자색 대비를 따로 잡아야 한다.
이건 이 방향이 지불하는 비용이고, 지금은 阪神만 구현돼 있다.

## 3. 블록 모델

선수 페이지 = **블록의 나열**. 사용자가 무엇을 켜고 어떤 순서로 볼지 정한다.

| 블록 | 내용 | 조작 |
|---|---|---|
| `standard` | 기본 성적 | — |
| `advanced` | 세이버 (wOBA·wRC+·SRC) | — |
| `splits` | 스플릿 | **축 전환**: 대투수좌우 / 주자상황 / 홈원정 / 월별 |
| `scorebook` | 타석 기록 (A안 유래) | 기간 |
| `situation` | 득점기대치 24칸 (B안 유래) | — |
| `matchup` | 대전 투수별 | — |
| `ranking` | 리그 순위 | **지표 전환**: wRC+ / SRC / OPS / 타율 / 홈런 |

### 프리셋 — **대부분의 사용자는 커스터마이즈하지 않는다**

| 프리셋 | 구성 | 대상 |
|---|---|---|
| 標準 | 기본 + 세이버 + 스플릿 + 순위 | 기본값 |
| 記録 | 기본 + 타석기록 + 스플릿 + 대전 | 기록을 읽는 사람 |
| 分析 | 세이버 + 득점기대치 + 스플릿 + 대전 + 순위 | 지표를 파는 사람 |
| 簡易 | 기본만 | 빨리 확인만 |

⚠**프리셋이 먼저고 조립은 나중이다.** 설정 화면부터 보여주는 도구는 아무도 안 쓴다.
「組み替え」 버튼을 눌러야 편집 UI가 나온다.

### 조립 UI

명감의 **색인 탭**에 가깝게 만든다 — 톱니바퀴 설정 아이콘을 쓰지 않는다.
체크박스로 켜고 끄고, ↑↓로 순서를 바꾼다.

## 4. ⚠사용자가 끌 수 없는 것

**비율 옆의 분모(타석 수·타수)는 항상 나온다.** 설정에서 지울 수 없다.

10타석 .400을 순위로 보여주지 않기 위한 규칙이고(M2), **취향이 아니다.**
편집 화면에 이 사실을 명시해서, 없는 기능을 찾게 만들지 않는다.

같은 이유로:
- **대전 성적에 순위를 매기지 않는다.** 대부분 10타석 미만이라 나열하는 순간 「이 투수에 강하다」로 읽힌다.
  타석 수 순으로 놓고, 10타석 미만은 색을 낮춘다.
- **스플릿 막대는 표본이 얇으면 칠을 약하게** 한다. 값은 그대로 보이되 시각적 무게를 뺀다.
- **득점기대치 칸도 표본 100 미만이면 흐리게.**

## 5. ⚠상위 규약과의 충돌 — 확인 필요

`CLAUDE.md` §6: 「값 강조 금지 — **라벨 강조 원칙**(항목명이 값보다 잘 보이게)」

이 규칙은 PPS(업무 포털)에서 확립됐고, 뜻은 **「의미를 모르는 값을 보여주지 마라」**였다.
그런데 통계 서비스에서는 **숫자가 곧 내용**이다. 항목명을 값보다 크게 하면 읽을 수 없는 화면이 된다.

**목업에서 내린 판단**: 값을 주역으로 두되, **분모와 라벨을 반드시 인접**시킨다.
규칙의 정신(모르는 값 금지)은 M2로 지키고, 형식(라벨을 더 크게)은 이 도메인에서 버린다.

→ **사용자 확인이 필요하다.** 승인되면 `CLAUDE.md` §6을 도메인 예외와 함께 고친다.
