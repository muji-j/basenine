# 현 화면 감사 — 「딱딱하다·투박하다·애니메이션이 없다」의 정체 (2026-09-07)

요청은 `2026-09-07-design-overhaul-request.md`. **이 문서는 그 요청의 세 불만을 인상이 아니라
실측으로 바꿔 놓은 것**이다.

⚠**순서를 바꿨다.** 처음에는 「HIG 정독 → 감사」로 잡았는데 **거꾸로가 맞다.**
HIG 를 먼저 읽으면 일반론을 들고 돌아오게 된다. **먼저 무엇이 문제인지 짚고, 거기에 답하는 절을 읽는다.**

**방법**: Playwright 로 화면 10종 × 폭 2종(390 / 1280)을 실제로 띄워 스크린샷과 계측을 떴다.
`file://` 이 아니라 `npm run preview` 서버로 열었다(CLAUDE.md §5 — `file://` 은 색인 fetch 가 막혀
검색이 죽은 화면을 재게 된다).

## 0. 먼저 — **이미 잘 되어 있는 것** (개선하다 부수면 안 되는 것)

- **색이 도메인에서 나왔다** — 감청·주황 강조·크림 바탕. 구단색은 작은 사각형으로 붙는다.
  ⚠**「AI틱함」 회피 목록과 거리가 멀다.** HIG 를 따르다 iOS 기본 파랑으로 수렴하면 **이걸 깨뜨린다.**
- **데이터 시각화가 작동한다** — 승패 막대 · 득실 막대가 표 안에서 값을 보조한다.
- **값이 주역이고 라벨·분모가 인접한다**(§6 의 도메인 예외 그대로).
- **상태를 색이 아니라 글자로 말한다**(`途切れていない` 등).
- 본문 **16px / 행간 24.8px(1.55)** — 읽기 자체는 무리가 없다.

모션·그림자 같은 것을 전역에 얹을 때 **이 화면이 먼저 무너진다.**

## 2. 「딱딱하다·투박하다」의 정체 — **공간이 아니라 선으로 구분한다**

넓은 화면(1280) 실측:

1. **같은 굵기의 1px 실선 사각형이 전부다.** 카드 테두리 + 안쪽 주황 세로줄 + 표 테두리가
   **몇 px 안에 선 3개**로 겹친다. 깊이도 부드러움도 없고, **여백이 할 일을 선이 하고 있다.**
2. **탭 줄이 각진 상자들**이다(`直近の結果` · `セントラル` …). 이 화면에서 **가장 낡아 보이는 요소**.
3. **세로 리듬이 불규칙하다** — 시즌 띠 → 알림 → 제목 → 탭 → 카드의 간격이 제각각이고
   눈에 보이는 척도가 없다.
4. **표에 호버도 줄무늬도 없다** — 평평하고, 1,180px 폭에 행이 끝까지 늘어나 **눈이 멀리 이동한다**
   (`全勝〜全敗の勝率` 열이 오른쪽 끝에 홀로 있다).
5. **상단 내비 10항목이 전부 같은 무게**라 묶음이 없다.

## 3. 좁은 화면(390)에서 더 나쁜 것 — ⚠**여기가 진짜 UX 문제다**

1. ⚠⚠**첫 화면에 가로 스크롤 영역이 4개** 쌓여 있다: **내비 · 시즌 띠 · 탭 줄 · 표**.
   **사용자가 어느 것을 밀어야 하는지 알 수 없다.** 「투박하다」의 상당 부분이 시각이 아니라 **이것**이다.
2. **카드가 화면 좌우 끝에 붙어 바깥 여백이 거의 0**이다 — 「여백 디자인이 투박하다」의 가장 큰 신호.
3. **내비의 `他大…` 가 단어 중간에서 잘린다.**
4. 표가 `ゲーム差` 에서 잘리고 나머지 열은 화면 밖이다.

## 4. 애니메이션 — 「거의 없다」가 맞다

지금 있는 움직임은 **탭 전환 시 패널 교체**와 **툴팁 표시**뿐이고 둘 다 즉시 전환이다.
⚠**모션을 더할 때 지킬 것**: `prefers-reduced-motion` 분기를 **처음부터** 넣는다(루트 §7).
⚠**서버가 없어 화면 이동은 실제 문서 이동**이다 — 페이지 전환 애니메이션은 원리적으로 못 한다.
**같은 문서 안**(탭·구획·툴팁·표 정렬)에서 벌어야 한다.

## 5. ⚠개선의 성공 조건 (이걸 어기면 개악이다)

- **표 한 줄에 들어가던 정보가 두 줄이 되면 안 된다** — 여백은 **위계를 만드는 데** 쓰고
  **밀도를 깎는 데** 쓰지 않는다.
- **각주를 지워서 세련되게 만들지 않는다** — 그건 이 사이트의 정직함이다.
  **읽기 쉬움과 정직함을 동시에** 만족시키는 것이 과제다.
- **색을 도메인에서 계속 뽑는다.**
- ⚠**`ranking.html`(42,703노드)에서 먼저 재고 나서 전역에 얹는다.**

## 6. 아직 안 한 것

- **HIG 정독** — 이 감사가 짚은 문제(공간 위계 · 탭/세그먼트 컨트롤 · 모션 · 좁은 화면 레이아웃)에
  **답하는 절부터** 읽는다.
- **다크 모드**를 안 봤다. 이 사이트가 그것을 갖는지도 아직 안 쟀다.
- **색 대비(WCAG AA)** 를 안 쟀다.
- **실기기**(진짜 손가락·스크린리더)로 안 봤다 — Playwright 헤드리스까지다.
