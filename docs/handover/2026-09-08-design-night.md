## 2. ⚠내가 기본값으로 정한 것 (사용자가 뒤집을 수 있다)

1. **부분집합의 CSS 패밀리명 = `BN Sans` / `BN Sans JP`** — IBM Plex 의 **예약 서체명이 `"Plex"`** 이고
   OFL 이 **글리프 삭제도 개변**으로 보기 때문. ⚠**안전한 쪽으로 고른 것이지 법률 판단이 아니다**
   (Google Fonts 는 같은 서체의 부분집합을 원래 이름으로 서빙한다 — 해석이 갈린다).
2. **`▸`→`▶` · `◂`→`◀`** — 네 서체 모두에 없던 두 글자. ⚠**`▶` 는 이모지 표현을 가진 글자**라
   배선 시 확인이 필요하다. 걸리면 **`›`/`‹`**.
3. **로딩 전략**: 400 만 `preload` · 600/700 은 `font-display:swap`.

## 3. ⚠밤새 드러난 것 중 **다음 사람이 반드시 알아야 할 것**

### 3-1. 「조용히 틀린다」가 **다섯 층**으로 겹쳐 있었다

각 층은 **그 위층을 고치는 과정에서만** 보였다:

1. 감사가 **분모가 안 읽히는 두 자리**를 찾음(M2 위반 · **P0**)
2. 고치려 보니 **그 결함이 기존 시험을 통과**하고 있었고, **허용목록 네 항목이 넷 다 틀린 값**이었다
   (다른 잉크를 다른 배경에서 쟀다). **시험은 그 문자열을 안 봤다.**
3. 1차 검토가 **비교표의 「이긴 쪽」이 낭독기에 전혀 안 들린다**를 찾음
4. 3차 검토가 **그 수술 자체의 구멍**을 찾음 — `#tip s` 만 잉크·배경이 리터럴로 남았고,
   **색이 뒤집히는 유일한 경우**였다
5. 고치려 보니 **`stripJsComments` 가 `${…}` 보간을 안 좇아 템플릿 역따옴표가 어긋나** 있었다

⚠**교훈: 「시험이 통과한다」와 「시험이 그것을 본다」는 다른 말이다.**
문자열로 적어 둔 근거는 **검사 가능한 주장으로 바꿔라.**

### 3-2. 순위 화면에 **이미** 4,453행 전부 트랜지션이 걸려 있다

내가 목업 담당에게 「행마다 전환을 걸면 이 화면이 무너진다」고 경고했는데 **그 상태가 이미 현실이었다.**
→ **2e 는 여기에 더하지 마라. 오히려 뺄 수 있는 자리다.**

### 3-3. ⚠**내 추정이 여러 번 빗나갔다 — 추정으로 쓰지 마라**

| 내가 적은 것 | 실측 |
|---|---|
| 전수 글자 「1,300~1,600자」 | **1,646자** |
| 「1,500자 WOFF2 = 80~200KB」 | **JP 한 웨이트 297 KiB**(한 자리 틀림) |
| 계획서 「파일 +17장」 | **+13장**(2005~2017 은 13년) |
| 이닝 경계 「84.4%」 | **분모가 틀렸다** — 실제 92.9% |

### 3-4. ⚠서체 측정 프로브가 **세 번** 거짓 통과를 냈다

⑴ 정착 시간을 안 줘 **빈 페이지**를 잼 · ⑵ **CSP `font-src 'self'`** 가 외부 폰트를 막는 걸 모름 ·
⑶ **`unicode-range` 슬라이스는 글자가 그려질 때 받는데** 측정용 요소를 만들자마자 지워 **폴백을 잼**.
→ **적용을 먼저 증명하라**(로드된 face 수 + 같은 글자 폭 변화). **증명 안 되면 「측정 실패」로 찍어라.**

## 4. ⚠아직 안 된 것 (「문제 없다」가 아니라 「안 했다」)

1. **`npm run build:fonts` 가 CI 에 안 걸려 있다** — `daily.yml` 이 `build.ts` 를 직접 부른다.
   **공급망 게이트(sha256)도 이름-개체 게이트도 지금은 로컬에서만 선다.**
2. **낭독기·실기기 확인 0** — 비교표 수정도, `▶` 도, 터치 타깃도 전부 계산·문자열까지다.
3. **Safari·Firefox 0** · **Mac(Hiragino 기준) 0**.
4. **우리 부분집합을 실제 브라우저에 씌워 본 적이 없다** — §5-D 는 Google 슬라이스로 쟀다.
5. **CI 에서 폰트 비용을 안 쟀다** — 로컬 훑기가 **캐시 상태에 따라 7배**(22.7~154.4초) 흔들린다.
6. **배포물 바이트가 1478.2 → 1487.1MB** 로 늘었는데 **원인을 안 쟀다**(이 변경 때문은 아니다 — HTML 무변경).
7. `design-auditor` 가 **안 본 것**: 경기 상세 화면 · `compare`/`matchup` 의 상호작용 상태 ·
   `pointer:coarse` 실제 렌더 · `forced-colors` 실행.
