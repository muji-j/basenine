## 2. ⚠이번 작업이 남긴 가장 값진 것 — **되풀이된 실패의 모양**

### 2-1. 캐스케이드 — **같은 실수를 여섯 번 했다**

| # | 어디 | 모양 |
|---|---|---|
| 1 | 2b `.tabs.seg` 복원 | 고른 탭의 테두리를 덮었다 |
| 2 | 2b `:not()` 특이도 | 호버를 눌렀다 |
| 3 | 2b seg 호버 | 다시 고른 탭을 덮었다 |
| 4 | 2c `.mfind .tab` | 굽기 전에 자수 |
| 5 | 2c 펼친 내비 padding | **손가락 보정을 눌렀다**(8px → 6px) |
| 6 | 2d 호버 box-shadow | **이긴 쪽이 나머지를 지웠다** |

⚠**여섯 번째만 모양이 다르다.** 앞의 다섯은 「누가 이기나」였는데 이번 것은
**「이긴 쪽이 나머지를 지운다」**다 — `box-shadow`·`transform` 처럼 **값이 통째로 갈리는 속성**에서는
특이도를 맞추는 것만으로 부족하다.

### 2-2. ⚠**「보이는가」를 셀 때는 `checkVisibility` 를 써라 — 하루에 세 번 밟았다**

`offsetParent` 로 세면 **`hidden=until-found` 패널 안의 요소가 「보인다」로 세어진다**
(`content-visibility:hidden` 이라 배치는 되지만 안 그려진다).
겹침 무리의 「과잉 적용」 오탐 · 블록 수 오계수 · 그 둘을 잡은 것도 같은 함정이었다.

### 2-3. ⚠**이 팔레트에서 「면」으로는 표식을 만들 수 없다 — 세 번 확인했다**

`--page : --panel` = **라이트 1.044 · 다크 1.084**, `--panel-2` 도 1.08~1.19.
2b 에서 두 번(패널의 「층」 · `.legend` 의 면), 2d 에서 한 번(**표 호버가 1.044**) 걸렸다.
**표식은 선으로 만든다** — 2b 가 세운 어휘: **칠해진 테두리 = 지금 고른 것이거나 손가락이 얹힌 것.**

### 2-4. ⚠**구단색을 「선」에 쓰지 마라 — 이 저장소가 네 번 같은 판정을 내렸다**

`.tbar i` · `.mf-shape`/`.mf-dot` · `.seasons a[aria-current]` · `.tnav`/`.brand`.
12구단 전수(`--panel` 대비): **라이트 4/12 · 다크 8/12 · 합집합 12/12** 가 3:1 미달.
**네 번 났다는 것은 기억으로는 안 막힌다는 뜻**이라 이제 **시험이 묶는다**
(「지금 여기 표식 셋이 한 잉크이고 구단색을 쓰지 않는다」).

### 2-5. ⚠**게이트가 설계를 고쳤다 — 두 번**

- **2c**: `<details>` 를 CSS 로 못 편다는 것을 **재고 나서** 체크박스로 갔다.
  JS 로 정하면 **defer 라 100ms 깜빡인다**(FCP 504ms · DCL 607ms · 실측).
- **3단계**: 「기본은 요청 0건」을 재 보니 **저장 noto 8개 · 저장 system 4개** 였다 —
  **기본이 아닌 것을 고른 사람이 손해**를 보고 있었다. 그래서 CSS 기본을 뒤집었다.

**둘 다 안 재 봤으면 그대로 배포했을 것이다.**

- **시험을 빌드보다 먼저 돌려라.** `assets.ts` 는 통째로 템플릿 리터럴이라 **주석의 역따옴표가

- **배포물에 나가는 글자는 ASCII 로 적어라.** CSS 표식 주석을 한국어로 썼다가
  **커버리지 게이트가 한글을 잡아 멈췄다**(`assets.ts` 의 주석은 `stripJsComments` 가 걷지만
  `build-fonts.ts` 가 붙이는 것은 그 경로를 안 지난다).
- **`gh` 활성 계정이 세션 도중 `jwlee-muji` 로 되돌아간다** — 이 작업 중 **네 번**.
  「권한 없음」이 뜨면 분류기가 아니라 **계정을 먼저 의심하라.**

## 5. ⚠사람이 봐야 하는 것 (계측기로 못 하는 것)

1. **문서 간 전환** — 실제로 도는지, **순위 화면(42,703노드)에서 걸리는 느낌**이 있는지.
   ⚠**발동을 증명하지 못했다**(계측기를 세 번 고쳐도 못 잡았다). 걸리면 CSS 두 줄만 지우면 원상복구다.
2. **서체** — `Plex` / `Noto` / `標準` 을 눌러 비교. 실회선에서 297 KiB 가 어떤지.
3. **모바일** — 내비·목차 접기가 손에 맞는지.
4. **낭독기** — 접기를 체크박스로 만들어서 「체크박스」로 읽힌다. `aria-controls` 만 줬고
   `aria-expanded` 는 **일부러 안 줬다**(스크립트 없이는 갱신이 안 돼 **틀린 값이 고정된다**).
5. **Safari · Firefox · Mac** — 전부 미확인이다. 특히 **문서 간 전환은 그 둘에서 무변화**여야 한다.

### ⚠이번에 배운 것 — **재기 전에 쓴 문장이 틀렸다**

`@media (pointer:coarse)` 주석에 **「.hjlab·.snbtn 은 기본값이 이미 손가락에 맞는다」**고 적었다.
**재 보니 둘 다 22.3px 이었다**(마우스·손가락, 390·1280px 네 지점 전부). 근거 없이 쓴 문장이었고,
그 문장이 그대로 남았으면 **다음 사람이 「이미 쟀다」고 읽었을 것**이다.
→ 그 자리에 **틀렸다는 사실과 실측값**을 남겼다.

### ⚠고정(sticky)을 걷어낸 이유 — 상수를 박을 수 없어서다

2f 전 `.hjump` 는 **한 줄을 가로로 굴리는 띠**라 높이가 **52px 로 고정**이었고,
그래서 `scroll-padding-top` 사다리에 52 를 박을 수 있었다. 2f 가 **줄바꿈 + 접기**로 바꾸자
높이가 **43.3 ~ 122.5px** 로 움직였다(684~1456px step 28 · 전 시즌 홈 9장 · 최대는 684px).

- ⚠**폭으로 구간을 나누는 우회도 못 쓴다** — **서체가 3종**이라 줄바꿈 지점이 사용자 선택에 따라 움직인다.
- → **고정을 버렸다.** 사다리는 기본 규칙(`--topbar + --s4`)으로 돌아갔고 **척도 이탈이 2 → 1 로 줄었다.**
- 실측 확인: 앵커 **35회**(항목 7 × 폭 5)에서 가장 나쁜 여유 **+7.5px** — 가려지는 것 0.

### 시험이 세 번 붙잡았다 (전부 진짜였다)

1. `sticky-anchor` — `.hjbar` 를 sticky 로 만들고 사다리에 안 넣었다 → 위 결론으로 이어졌다.
2. `css-tables` — 반지름 규칙이 `.scroller{` 리터럴을 **앞에서 가로채** 시험이 엉뚱한 규칙을 읽었다.
   → **첫 일치**가 아니라 **전건**을 모으게 고쳤다(뮤테이션 검사로 확인: `overflow-x` 를 빼면 붉어진다).
3. `design-tokens` — `border-bottom:0` 이 척도 밖으로 잡혔다 → `none` 으로 바꿨다(굵기가 아니라 「안 그린다」).

## 6. 남은 일

- **은퇴 저장소(`bb-app`)의 `design-2a` 브랜치 삭제** — 사용자 승인이 필요하다.
- ⚠**`$CLAUDE_JOB_DIR/tmp` 가 계속 자란다**(8월 16일부터 누적 · 한때 6.5GB).
  **자기가 만든 것만 이름을 적어 지워라** — 다른 세션 것이 섞여 있다.
