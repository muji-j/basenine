# @bb-app/parser

아카이브한 npb.jp 원시 HTML을 구조화 레코드로 바꾼다. 소스별 **1벌**만 존재한다(CLAUDE.md M1).

## 실측으로 확인된 것 (2026-08-15 · 351경기)

### ⚠박스스코어 타격표에는 볼넷·삼진·장타 컬럼이 없다

컬럼은 `打数 得点 安打 打点 盗塁` **다섯 개뿐**이다. 나머지는 전부 **타석별 결과 셀**에 문자열로 들어 있다.

```
村林  6 1 2 0 0 | 二ゴロ | 左前安 | - | 遊ゴロ | ... | 三 振
```

즉 wOBA·FIP·K%가 요구하는 입력(BB·HBP·SO·2B·3B·HR·SF·ROE)을 얻으려면 **결과 셀을 해석해야 한다.**
`src/tokens.ts`가 그 일을 하며, **이 프로젝트에서 가장 깨지기 쉬운 지점**이다.

### 결과 셀 문법

```
토큰 := <수비위치·방향><결과어><루타 全角숫자?><타점 丸数字?>
```

| 예 | 해석 |
|---|---|
| `三 振` | 삼진 |
| `四 球` / `敬遠四` / `死 球` | 볼넷 / **고의사구** / 사구 |
| `中前安` / `左前安①` | 단타 / 단타 + 타점 1 |
| `左線２` / `右中３①` / `左越本②` | 2루타 / 3루타+타점1 / 홈런+타점2 |
| `二ゴロ` `中 飛` `捕邪飛` `遊 直` | 아웃 |
| `三ゴ失` / `遊ゴ失①` | **실책 출루** |
| `投犠打` / `中犠飛①` / `投犠野` / `投犠失` | 희생번트 / 희생플라이 / 희생번트+야수선택 / 희생번트+실책 |
| `振逃` | 낫아웃 출루 |
| `打妨出` | 타격방해 출루 |

### 함정 세 가지 (전부 실제로 밟았다)

1. **`三振`(삼진)과 `三ゴロ`(3루수 땅볼)는 둘 다 `三`으로 시작한다.**
   수비 위치로 앞을 자르면 반드시 틀린다 → **결과어를 접미사로 본다.**
2. **`犠`(희생)가 들어가면 뒤에 무엇이 붙어도 희생타로 기록되어 타수가 아니다.**
   `投犠失`를 `失` 규칙으로 먼저 잡아 실책 출루로 분류했더니 **타수가 19건 어긋났다.**
   → 희생 계열을 규칙 최상단에 둔다.
3. **헤더 레이아웃이 23종이다.** 연장전이면 이닝 컬럼이 늘고, 빈 스페이서 컬럼이 끼는 변형도 있다.
   → **컬럼 인덱스를 고정하지 않는다.** 헤더에서 `盗塁` 위치를 찾아 그 다음부터를 타석 셀로 잡는다.
4. **`投球回` 셀 안에 중첩 테이블이 있다.**
   ```html
   <td><table class="table_inning"><tr><th>6</th><td>.2</td></tr></table></td>
   ```
   안쪽 `</table>`이 바깥 표의 비탐욕 매칭을 먼저 끊고, 안쪽 셀이 먼저 잡혀 **투수 성적이 전부
   한 칸씩 밀려 null이 됐다.** → 셀을 나누기 **전에 문서 전체를 평탄화**한다.
5. **투수표에도 `チーム計` 합계 행이 있다.** 함께 더하면 **정확히 2배**가 된다.

### 소스 조사 결론의 정정

| 항목 | 조사 단계 판정 | 실측 결과 |
|---|---|---|
| 선수별 **실책 출루(ROE)** | 「공개 소스 없음」 → wOBA 항 생략 | **박스스코어 셀에 존재**(340경기 214건). **wOBA를 생략 없이 계산한다** |
| **고의사구(IBB)** | 미확인 | `敬遠四`로 구별 가능(85건). wOBA의 `四球−故意四球`를 정확히 계산 |

## 자기 검증 — `tools/sweep-archive.ts`

두 축으로 **외부 정답과 맞춰본다.** 우리 산식으로 우리 산식을 검증하는 게 아니다.

1. **타격** — 박스스코어는 `打数`·`安打`·`打点`을 컬럼으로도 주고 타석 셀로도 준다.
   셀에서 도출한 값이 그 합계와 어긋나면 **토큰 해석이 틀린 것**이다.
2. **투수** — 한쪽 투수진의 피안타 합계는 **상대 타자진의 안타 합계**와 같아야 한다.
   컬럼이 한 칸이라도 밀리면 여기서 드러난다. ⚠**이 대조가 없던 동안 투수 성적은
   전부 null인 채로 「정상」이었다** — 타격만 검증하면 절반은 안 본 것이다.

```bash
node packages/parser/tools/sweep-archive.ts data/archive
```

## 설계 원칙

| 규칙 | 구현 |
|---|---|
| **M7** 실패는 실패로 | 헤더에서 필수 열을 못 찾으면 예외. **빈 결과를 돌려주지 않는다** |
| **M7** 구조 변경 감지 | 타격표가 없는데 `中止` 표기도 없으면 예외 |
| **M11** 결측 3분류 | 중지 경기는 오류가 아니라 `status: "notPlayed"`. 빈 수치 셀은 `null`(0 아님) |
| **격리** | 모르는 토큰은 버리지 않고 `outcome: "unknown"` + 원문 보존. 호출자가 **반드시 세어서 보고** |
| 팀 합계 행 | 버리지 않고 `isTeamTotal`로 표시 — 대조에 쓸 수 있다 |
